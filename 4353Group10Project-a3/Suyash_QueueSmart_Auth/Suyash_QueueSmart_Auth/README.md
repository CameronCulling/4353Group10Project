# QueueSmart A2 — Login and Registration pages

This folder contains the login and registration UI contribution: `index.html`, `register.html`, and `auth.css`. It uses HTML and CSS only, and adjusts to phone, tablet, and laptop widths.

## Add to the group project

Copy these three files into the root of the group's website repository. The sign-in page is `index.html`. The forms link to the team's `dashboard.html`, and the staff preview link goes to `admin.html`; those pages are made by other group members. If the team uses different filenames, change those `href` and `action` values when integrating.

Open `index.html` and `register.html` in a browser to review both layouts. Try an empty field, an invalid email, and a password under eight characters to see the browser's built-in validation. The forms do not create or verify accounts, and no email or password is submitted in the URL. The account type field is a visual preview: selecting Administrator does not change the destination or grant access. Use sample details only.
